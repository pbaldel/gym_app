# Gym Log

PWA personal para registrar entrenamientos de fuerza (iPhone, Safari, 100 % offline). Ver `CLAUDE.md` para el diseño completo.

```bash
npm install
npm run dev                  # servidor de desarrollo
npm run build                # typecheck + build de producción en dist/
npm run preview              # sirve dist/ (para probar el service worker)
npm test                     # Vitest
npm run generate-pwa-assets  # regenera los iconos desde public/logo.svg
```
